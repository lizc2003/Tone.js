🎵 TimeStretchPlayer Demo

⚠️ Note: TimeStretchPlayer uses SoundTouch via AudioWorklet for real-time time-stretching and pitch-shifting. This allows you to:
  • Tempo: Change playback speed without affecting pitch
  • Pitch: Change pitch (in semitones) without affecting speed
Status: Ready - Click Start to begin

Usage Example (Code)

// Load SoundTouch WASM and JS code
const wasmResponse = await fetch('./soundtouch/soundtouch_bg.wasm');
const wasmBytes = await wasmResponse.arrayBuffer();
const soundtouchCode = await (await fetch('./soundtouch/soundtouch_worklet.js')).text();

// Create TimeStretchPlayer
const player = new Tone.TimeStretchPlayer({
  url: "audio.mp3",
  loop: true,
  tempo: 1.0,
  pitch: 0,
  onload: () => console.log('Loaded!')
}).toDestination();

// Load SoundTouch dependencies
await player.loadSoundTouch(wasmBytes, soundtouchCode);

// Start playback
player.start();

// Change tempo (1.5 = 50% faster, no pitch change)
player.tempo = 1.5;

// Change pitch (+5 semitones, no speed change)
player.pitch = 5;
